## Introduction
A CLI tool to start a local [Collab API](https://github.com/ueberdosis/collab-api) server – useful for quickly spinning up a collaboration backend for development, demos, or simple deployments, with optional SQLite, S3, logger, and webhook extensions.

```bash
npx @collab-api/cli
```
