## Introduction
Shared types and utilities used across [Collab API](https://github.com/ueberdosis/collab-api) packages – including message/sync protocol helpers and common enums. This package is an internal building block; most users will depend on `@collab-api/server` or `@collab-api/provider` instead.

## Official Documentation
Documentation can be found in the [GitHub repository](https://github.com/ueberdosis/collab-api).
